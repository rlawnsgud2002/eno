이노베이스 GPS 프로그램 사용법

1. Python 3.12 64비트를 설치합니다.
   공식 설치 주소: https://www.python.org/downloads/windows/

2. 이 압축파일의 내용을 모두 압축 해제합니다.
   ZIP 안에서 직접 실행하지 마세요.

3. 이노베이스_GPS_프로그램.bat을 더블클릭합니다.
   첫 실행 때 필요한 라이브러리를 설치합니다. 인터넷 연결이 필요합니다.

4. GPS 원본 Excel이 들어 있는 폴더의 전체 경로를 입력합니다.
   예: D:\GPS원본
   원본 폴더를 BAT 파일 위로 끌어놓아 실행할 수도 있습니다.
   원본은 프로그램 폴더 밖에 보관하세요.

5. 완료되면 output 폴더가 열립니다.
   아산시_21대차량_2026년4월~8월_방문장소_통합분석.xlsx를 열면 됩니다.

API 키 없이도 실행됩니다. 장소명은 미확인으로 남을 수 있습니다.
V-World는 .env.example을 .env로 복사해 키를 설정한 뒤
verify_vworld.bat으로 먼저 확인하세요. 자세한 설정은 README.md에 있습니다.

sample_reports 폴더에는 실제 하루 샘플 분석 보고서가 들어 있습니다.
프로그램의 Windows 실기 실행과 실제 API 연결은 아직 검증하지 않았습니다.
원본 GPS 파일과 실제 인증키는 이 압축에 포함되어 있지 않습니다.
